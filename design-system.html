System foundations

Precise by default.
Institutional by intent.

Flux is designed for finance teams making high-consequence operational decisions. The system prioritizes scanability, control visibility, dense information and restrained hierarchy over consumer-fintech decoration.

DirectionPrecise / Institutional / Efficient
Primary userFinance Manager / CFO

Typography

IBM Plex Sans carries hierarchy and interface language. IBM Plex Mono is reserved for operational evidence: money, IDs, timestamps, rules and thresholds.

01.06

Motion principles

Motion explains state change and workflow continuity. It should never compete with transaction data.

Purpose

Clarify change

Use motion for selection, panel continuity, approval progression and successful state transitions.

Timing

Fast and functional

Prefer short transitions around 120–220ms with no decorative overshoot.

Accessibility

Reduced motion

Preserve visibility and information hierarchy when prefers-reduced-motion is enabled.
